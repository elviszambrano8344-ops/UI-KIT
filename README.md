# UI Kit - Sistema Help Desk

## Descripción

Este proyecto corresponde al desarrollo de una librería de componentes UI (Design System) para un sistema Help Desk, utilizando HTML5 y CSS3.

El objetivo es disponer de componentes reutilizables que mantengan una apariencia visual uniforme y organizada para futuras páginas del sistema.

## Componentes implementados

- Botón primario
- Botón secundario
- Botón de peligro
- Campos de formulario (Input)
- Lista desplegable (Select)
- Tarjetas (Cards)
- Badges de prioridad (Alta, Media y Baja)

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Estructura del proyecto

```
UI-KIT/
│── index.html
│── style.css
│── README.md
```

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir el archivo `index.html` en cualquier navegador web.
3. Los estilos se cargan automáticamente desde `style.css`.
